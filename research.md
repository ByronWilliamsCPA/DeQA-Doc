## 1. Executive Summary

This document summarizes the research, analysis, and planned technical direction for enhancing the SigLIP2-IQA-Base-86M document image quality assessment model. The work covers three interconnected areas: expanding training data beyond the DIQA-5000 benchmark through VLM-generated pseudo-labels, validating VLM scoring accuracy against human ground truth, and distilling frontier model knowledge into a lightweight local model.

**Current State:** SigLIP2-IQA-Base achieves VQualA 0.886 on DIQA-5000, outperforming all pretrained IQA models (+22% over MANIQA) and all VLM approaches (+10% over DeQA-Doc) at 30x faster inference (~100ms). The target is VQualA 0.92.

**Planned Direction:** Use Claude Sonnet 4.6 as a teacher model to generate quality labels on diverse document types, validate correlation against DIQA-5000 human MOS scores, then distill into the SigLIP2 model via Unsloth for local deployment. This is paired with architectural improvements to the SigLIP2 model itself.

## 2. DIQA-5000 Dataset Analysis

The DIQA-5000 dataset was created for the VQualA 2025 challenge at ICCV. It comprises 5,000 document images generated by applying randomized enhancement pipelines (dewarp, demoiré, occlusion removal, deblur, deshadow, appearance enhancement) to 500 base images captured with five distortion types (shadow, occlusion, blur, creases, moiré).

Each image was rated by 15 human subjects across three dimensions: overall quality, sharpness, and color fidelity, producing continuous Mean Opinion Scores (MOS) on a 1–5 scale. The dataset provides only MOS means without per-rater variance data.

**Key finding:** The dataset does not include per-image metadata about which specific enhancement methods were applied. The processing pipeline used randomized combinations across six operation stages, but the provenance chain is not recorded in the released annotations. The dataset is gated behind the CodaLab competition platform.

## 3. Current Model Performance

### 3.1 SigLIP2-IQA-Base-86M Architecture

The model uses a SigLIP 2 ViT-B/16 backbone with NaFlex (Native Flexible Resolution) for variable aspect ratio preservation. Three independent regression heads predict quality scores with Gaussian uncertainty estimation (μ, σ²) for each dimension.

| Component | Detail |
|---|---|
| Backbone | google/siglip2-base-patch16-naflex (86M params) |
| Head Architecture | Linear(768→256) → ReLU → Dropout(0.3) → Linear(256→2) |
| Head Parameters | ~1.6M total across 3 heads |
| Max Patches | 576 (≈384×384 effective resolution) |
| Training | Two-phase: 10 epochs head warmup + 40 epochs full fine-tuning |
| Loss | NormInNormLoss + GaussianNLLLoss |
| Training Time | ~4 hours on NVIDIA A10 (24GB) |

### 3.2 Benchmark Results

| Model | SRCC Overall | VQualA | Inference |
|---|---|---|---|
| **SigLIP2-IQA-Base (ours)** | **0.896** | **0.886** | ~100ms |
| DeQA-Doc-3Specialists (VLM) | 0.733 | 0.786 | ~3000ms |
| MANIQA (pretrained) | 0.526 | 0.563 | ~1845ms |
| PyIQA-liqe (pretrained) | 0.403 | 0.511 | ~150ms |
| PyIQA-hyperiqa (pretrained) | 0.236 | 0.327 | ~152ms |

### 3.3 Gap Analysis

The primary gaps to the 0.92 VQualA target are in sharpness (0.869 vs 0.90 target, −3.1%) and color fidelity (0.885 vs 0.90, −1.5%). Overall quality has already reached 0.896, meeting its 0.90 target. The sharpness gap is the largest contributor to the VQualA shortfall.

## 4. VLM Teacher Model Strategy

### 4.1 Problem Statement

The DIQA-5000 training set has only 3,500 images, all derived from 500 base documents with specific distortion types. To generalize across diverse document types (tax forms, legal documents, handwritten notes, receipts), we need labeled data for these domains. Deploying 15 human raters is infeasible; instead, we use frontier VLMs as pseudo-raters.

### 4.2 Top 10 Models Evaluated

We evaluated models across vision benchmarks (MMMU, DocVQA, OCRBench, Q-Bench), IQA-specific literature (DeQA-Score, Q-Align, AgenticIQA), and deployment practicality. The ranking considers document understanding strength, calibration quality, cost, and local deployment feasibility.

| Rank | Model | Rationale | Deployment |
|---|---|---|---|
| 1 | Qwen3-VL-235B-A22B | Strongest open-weight VLM; rivals Gemini/GPT-5 on doc benchmarks; 32-lang OCR | API (Alibaba/OpenRouter) |
| 2 | Gemini 3 Pro | Top proprietary vision; MMMU Pro leader; strong doc understanding | API ($2/$12 per 1M tok) |
| 3 | Claude Opus 4.6 | 91.3% GPQA; best reasoning depth; gold-standard anchor labels | API ($5/$25 per 1M tok) |
| 4 | Qwen3-VL-8B | Validated zero-shot; 32-lang OCR; runs locally on P40 GPU | Local (P40, free) |
| 5 | Claude Sonnet 4.6 | Best cost/quality ratio; 1633 Elo office tasks; strong instruction following | API ($3/$15 per 1M tok) |
| 6 | InternVL3-78B | 72.2 MMMU; 92.7 DocVQA; independent model family for diversity | API / cloud GPU |
| 7 | Gemini 3 Flash | 79% MMMU Pro; cheapest high-quality API option | API ($0.50/$3 per 1M tok) |
| 8 | Qwen2.5-VL-7B | 95.7 DocVQA; proven DIQA base (DeQA-Doc, Q-Probe winners used it) | Local (P40, free) |

| 10 | DeepSeek-OCR | 97% OCR accuracy at 20x compression; 100-lang support | Local / API |

### 4.3 Recommended Teacher: Claude Sonnet 4.6

Sonnet 4.6 is the primary recommendation for bulk pseudo-label generation based on cost efficiency ($3/$15 per 1M tokens), instruction-following reliability (critical for consistent structured JSON output across thousands of images), and strong vision capabilities nearly matching Opus 4.6 for structured tasks. Rating 5,000 images at 5 passes each would cost approximately $50–75.

Opus 4.6 serves as the escalation model for tiebreaker ratings where Sonnet and local models disagree, and for establishing gold-standard anchor labels on a small calibration set.

## 5. Correlation Validation Plan

### 5.1 Rationale

Before generating pseudo-labels, we must validate how well the VLM correlates with DIQA-5000 human MOS scores. If the teacher's correlation is lower than the student's current performance, naïve distillation would degrade the model. The DIQA-5000 test set (1,000 images with human MOS ground truth) serves as the calibration benchmark.

### 5.2 Implementation

An evaluation harness has been developed (`modal/eval_vlm_diqa_correlation.py`) that sends DIQA-5000 images to the VLM API, collects structured quality ratings, and computes per-dimension SRCC and PLCC against human MOS. Key features include multi-pass variance estimation (simulating rater disagreement via temperature sampling), rate limiting and retry logic, resume support for interrupted runs, and periodic checkpointing.

### 5.3 Metrics and Decision Criteria

| VLM SRCC Range | Distillation Recommendation | Label Weight |
|---|---|---|
| ≥ 0.90 | Strong teacher — use labels at full weight | 1.0 |
| 0.80 – 0.89 | Moderate teacher — use with reduced weight or rank-only | 0.5–0.8 |
| < 0.80 | Weak teacher — do not use for that dimension | 0.0 |

Per-dimension thresholds allow selective use: a VLM strong on overall quality but weak on color fidelity should only contribute labels for the dimensions where it exceeds the threshold.

### 5.4 Execution Plan

1. Quick sanity check: 10 images, 1 pass (~$0.15, 5 minutes)
2. Full test set baseline: 1,000 images, 1 pass, temp=0.0 (~$12–15, 45 minutes)
3. Multi-pass variance: 1,000 images, 5 passes, temp=0.7 (~$60–75, 3–4 hours)
4. Repeat with Qwen3-VL-8B locally for comparison signal (free)

## 6. Distillation & Training Pipeline

### 6.1 VLM Label Generation

Once correlation is validated, generate Sonnet 4.6 labels for 5,000–10,000 diverse documents covering target domains (tax forms, legal documents, scanned correspondence, handwritten notes, receipts). Each image is rated 3–5 times with temperature 0.7 to produce both mean scores and pseudo-variance per dimension. The reasoning field is included for chain-of-thought distillation.

### 6.2 Rating Scale

VLM prompts use a 1–10 scale with 0.5 increments (19 effective levels) to give the model more expressive room in the mid-range. Scores are linearly mapped to 1–5 MOS-compatible values (divide by 2) for training, preserving benchmark compatibility with DIQA-5000.

### 6.3 Training Data Composition

The training set combines DIQA-5000 human MOS labels (gold standard, full weight) with VLM pseudo-labels (weight scaled by per-dimension SRCC from the correlation study). The loss function applies dataset-specific weighting to ensure human labels anchor the model while VLM labels expand domain coverage.

### 6.4 Unsloth Distillation Path (Alternative)

For teams wanting a generative VLM scorer rather than a regression model, Unsloth enables SFT distillation of Sonnet 4.6's scoring behavior into Qwen3-VL-8B or Qwen2.5-VL-7B via LoRA fine-tuning. Unsloth supports VLM vision fine-tuning with 60% less VRAM, and the resulting model runs locally on the P40. This path produces a model that outputs structured JSON ratings with reasoning, rather than raw scores. GRPO reinforcement learning after SFT, using Sonnet score correlation as reward, can further improve calibration.

## 7. SigLIP2-IQA-Base v2.0 Improvements

Independent of the VLM distillation work, the following architectural and training improvements target the remaining VQualA gap. These are prioritized by expected impact and implementation effort.

| Priority | Improvement | Expected Impact | Effort |
|---|---|---|---|
| Tier 1 | Increase max_num_patches 576→784+ | +2–3% sharpness SRCC; resolves resolution ceiling for dense text | Low |
| Tier 1 | CosineAnnealingWarmRestarts scheduler | Prevents premature convergence from OneCycleLR aggressive decay | Low |
| Tier 1 | Gradient accumulation (batch 4×4) | Re-enables PCGrad in Phase 2 within memory budget | Low |
| Tier 1 | Attention pooling per dimension | Lets sharpness head attend to text regions, color head to chromatic regions | Medium |
| Tier 2 | Reduce dropout 0.3→0.1–0.15 | 0.3 is aggressive for regression with 3,500 samples | Low |
| Tier 2 | Wider/deeper heads (768→512→256→2) | More capacity for dimension-specific feature extraction | Low |
| Tier 2 | LLRD (0.9 decay/layer) | Better fine-tuning stability across backbone layers | Low |
| Tier 2 | MarginRankingLoss | Direct SRCC optimization via pairwise ranking | Medium |

## 8. Compliance Considerations

The local Qwen3-VL-8B model processes all images on-premises with zero data leaving the network, satisfying IRS Pub 4557 requirements for tax practice document handling. When using Claude API for pseudo-label generation, only DIQA-5000 benchmark images (publicly sourced documents) and non-client documents should be sent. Client documents must never be sent to external APIs for rating.

For production deployment, the SigLIP2-IQA model runs entirely locally with no external dependencies, ONNX export is planned for CPU-optimized edge inference, and all model artifacts are stored in GCS under project-controlled buckets.

## 10. Recommended Execution Sequence

1. **Run correlation validation** — Execute `eval_vlm_diqa_correlation.py` against DIQA-5000 test set with Sonnet 4.6. This provides the empirical basis for all downstream decisions. (1–2 days)

2. **Implement Tier 1 model improvements** — Increase patch count, swap scheduler, enable gradient accumulation. These are independent of the VLM work and can proceed in parallel. (2–3 days)

3. **Analyze correlation results** — Determine per-dimension label weights based on SRCC thresholds. Decide which dimensions to use from which VLM. (1 day)

4. **Generate expanded training labels** — Collect 5,000+ diverse document images and rate via Sonnet 4.6 with calibrated prompts. (3–5 days including image collection)

5. **Retrain SigLIP2 v2.0** — Combined DIQA-5000 human labels + VLM pseudo-labels with weighted loss, incorporating all Tier 1 architectural improvements. Validate against DIQA-5000 test set and new document holdout. (2–3 days)

6. **Evaluate and iterate** — If VQualA target 0.92 is not met, apply Tier 2 improvements (attention pooling, LLRD, ranking loss) and consider the Unsloth VLM distillation path as a complementary model. (Ongoing)
