# Data Inventory

Catalog of all datasets, model predictions, embeddings, and evaluation artifacts in the project.

---

## 1. Primary Datasets

| Dataset | Location | Images | Splits | Annotations |
|---------|----------|--------|--------|-------------|
| DIQA-5000 | `Data-DeQA-Score/DIQA/` | 5,000 | Train: 3,500 / Val: 500 / Test: 1,000 (+ 500 private) | MOS from 15 human raters, 3 dimensions |
| KONIQ-10k | `Data-DeQA-Score/KONIQ/` | ~10,000 | Train: 7K / Test: 2K | MOS (natural images, used for pretraining) |
| Synthetic OOD | Generated by `results/vlm_teacher_eval/full_eval/run_synthetic_eval.py` | 520 | Single set | 13 categories, MOS from generation params |

## 3. SigLIP2 Predictions and Embeddings

All extracted from `siglip2_iqa_best.pt` checkpoint via Modal L4 GPU. Each JSONL record: 20 fields (image, split, IQA mu/sigma_sq x 3 dims, script prediction + 19-class distribution, source/orientation/shadow/warping predictions, inference time).

| File | Split | Records | Size |
|------|-------|---------|------|
| `results/siglip2_diqa5000/siglip2_diqa5000_train.jsonl` | Train | 3,500 | 4.5 MB |
| `results/siglip2_diqa5000/siglip2_diqa5000_val.jsonl` | Val | 500 | 647 KB |
| `results/siglip2_diqa5000/siglip2_diqa5000_test.jsonl` | Test | 1,000 | 1.3 MB |
| `results/siglip2_diqa5000/embeddings/train.npz` | Train | (3500, 768) float32 | ~10 MB |
| `results/siglip2_diqa5000/embeddings/val.npz` | Val | (500, 768) float32 | ~1.5 MB |
| `results/siglip2_diqa5000/embeddings/test.npz` | Test | (1000, 768) float32 | ~3 MB |
| `results/siglip2_diqa5000/summary.json` | — | Metadata | JSON |

IQA output range: mu in [-0.17, 0.73]. Rescale to MOS [1,5] via `mu * 4.0 + 1.0`.
