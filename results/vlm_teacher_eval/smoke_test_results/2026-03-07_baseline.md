## Observations

1. **Score consistency**: All five access methods return identical numeric scores at temp=0, confirming the same scoring calibration regardless of provider, context window size, or model tier (Sonnet vs Opus).
2. **Context window has no effect on scores**: `claude-sonnet-4-6` and `claude-sonnet-4-6[1m]` are the same model — the 1M context variant only affects how much prior conversation history is available, not the model's visual perception or scoring calibration.
3. **Opus vs Sonnet — same scores, richer reasoning**: Opus 4.6 produces identical numeric scores but notably more detailed reasoning: identifies the subject by name ("likely the Singapore Flyer"), explains the physics of the blur ("sinusoidal light trails from camera shake during a long exposure"), and enumerates more specific colors (green accents, dark water reflections). This suggests Opus is a better choice when reasoning quality matters (e.g., for generating training rationales) but unnecessary for numeric scoring alone.
4. **Sonnet reasoning variation**: Minor wording differences across Sonnet runs ("the blur and dark exposure" / "the extreme blur" / "white Flyer neon") — expected free-form text variation even at temp=0. All Sonnet descriptions are substantively identical.
5. **Latency**: Anthropic direct is ~15% faster than OpenRouter (3.5s vs 4.1s), consistent with removing one routing hop. Extension calls have no measurable round-trip.
6. **Image suitability**: singapore_flyer.jpg is a motion-blurred nighttime photo, not a document. All models correctly identify this and rate it very low. Future smoke tests should include a document image for more representative IQA scores.
